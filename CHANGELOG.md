# Changelog

## 0.1.0

- Initial public beta as `mrjk.varstore` (import `varstore`).
- Hierarchical sources / scopes / layers via `StoreManager`.
- Template rendering via `RenderableStoreManager` (expandvars + `py_stringtemplate`).
- Vendored shell expand engine under `varstore.expand` (formerly varmgr + expandvars fork).
- Project scaffold from universal-templates `python-lib` (mise, uv, Taskfile, CI, docs).
